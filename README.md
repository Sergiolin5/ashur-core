# Ashur Core

Ashur es una IA personal que aprende de los chats, el diario, el uso del tiempo y los hábitos de Sergio.
Este monorepo contiene su core, su app y sus módulos.

| Carpeta | Contenido |
| --- | --- |
| `core/` | Servidor REST: memoria, chat, inventario de objetos físicos y contactos. |
| `app/` | Cliente Flutter para iOS, macOS, Windows y Android. |
| `modules/` | Módulos independientes que se integran al core. |
| `contracts/` | Contratos de datos entre el core y la app. |
| `docs/` | Documentación y decisiones de arquitectura. |

Empieza por `docs/ASHUR.md`. Las reglas para trabajar en el repo están en `CLAUDE.md`.
